# 08 — Placa de entrenamiento integradora (capstone)

## Objetivo de aprendizaje (a desarrollar a fondo)

Combina fuente regulada + sistema mínimo de MCU + entrada con debounce +
salida acondicionada en una sola placa multi-hoja. Es el ejercicio que
demuestra que dominás el flujo completo de diseño de principio a fin.

**Prerrequisito**: todos los ejemplos anteriores (01-07)
